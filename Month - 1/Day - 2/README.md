## Conditional Statements

### if

```python
if age >= 18:
    print("Eligible")
```

### if-else

```python
if age >= 18:
    print("Eligible")
else:
    print("Not Eligible")
```

### if-elif-else

```python
if number > 0:
    print("Positive")
elif number == 0:
    print("Zero")
else:
    print("Negative")
```
