# 📚 Concepts Covered

## Python

### Variables

Variables store values that can be used later in a program.

### Data Types

* String (`str`)
* Integer (`int`)
* Float (`float`)
* Boolean (`bool`)

### Input and Output

#### Input

```python
name = input("Enter your name: ")
```

* `input()` receives user input.
* By default, it returns a string.

#### Output

```python
print("Hello", name)
```

* `print()` displays output to the screen.

### Type Conversion

```python
age = int(input("Enter age: "))
```

* Converts string input into an integer.

### Arithmetic Operations

```python
+
-
*
/
```

Used for mathematical calculations.

---

## DSA

### Algorithm

An algorithm is a step-by-step procedure used to solve a problem.

### Time Complexity

Time complexity measures how the amount of work grows as input size increases.

#### O(1) — Constant Time

* Work remains constant.
* Does not depend on input size.

Example:

```python
print(arr[0])
```

#### O(n) — Linear Time

* Work grows with input size.

Example:

```python
for item in arr:
    print(item)
```
