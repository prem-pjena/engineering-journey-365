## Key Takeaways
- `and` is stricter than `or` — `and` needs both True, `or` needs at least one
- `not` flips True ↔ False
- Strings MUST be in quotes when comparing
- Nested `if` lets you check multiple conditions in sequence
- Login validation is the real-world pattern for all these concepts
