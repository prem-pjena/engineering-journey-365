## Topics Learned

### Python
- **`while` loops:** Repeat code while a condition is True
- **Loop counters:** Variables that track iterations
- **`break`:** Immediately exit the loop
- **`continue`:** Skip to the next iteration
- **Infinite loops:** How they happen and how to avoid them
- **Retry logic:** `while` loops with attempt limits
- **Menu-driven programs:** `while True` with user choices

### DSA
- **Iteration:** Repeating operations until a condition is met
- **Linear iteration complexity:** O(n)
- **Loop execution flow:** Initialize → Check Condition → Execute → Update → Repeat
