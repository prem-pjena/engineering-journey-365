# 📋 Immigration Checklist — Germany

**Last Updated:** 2026-07-04

---

## EU Blue Card — Requirements

### Basic
- ✅ Recognized university degree (B.Tech CSE ✅)
- ✅ Job offer from German employer (min salary threshold)
- Health insurance coverage
- Valid passport

### Salary Thresholds (2026)
| Type | Min Annual Salary |
|------|------------------|
| Regular Blue Card | ~€43,800 |
| IT Professionals | ~€39,683 |
| Shortage occupation | Lower threshold |

*Thresholds change yearly. Check closer to application date.*

---

## Application Process

### Step 1: Job Search (India)
- [ ] Build exceptional portfolio (by 2028)
- [ ] German language B2 (by 2028)
- [ ] Apply to German companies
- [ ] Clear interviews → receive offer

### Step 2: Visa Application
- [ ] Gather documents (see below)
- [ ] Appointment at German embassy/consulate (Delhi/Mumbai/Bangalore/Chennai)
- [ ] Submit application
- [ ] Processing: 4-12 weeks

### Step 3: Relocate
- [ ] Travel to Germany
- [ ] Register address (Anmeldung) — within 14 days
- [ ] Open German bank account
- [ ] Get health insurance
- [ ] Get tax ID
- [ ] Apply for Blue Card at local Foreigners Office (Ausländerbehörde)

### Step 4: Settle
- [ ] Find apartment
- [ ] Register for German classes (if continuing)
- [ ] Build routine
- [ ] Integrate

## Document Checklist

### For Visa Application
| Document | Notes |
|----------|-------|
| Valid passport | 6+ months validity |
| Degree certificate + transcripts | B.Tech CSE. May need recognition/anabin check |
| Job offer/contract | From German employer |
| CV | English + German version |
| Proof of German language | B2 Goethe certificate (target) |
| Health insurance proof | Valid for Germany |
| Blocked account? | Not needed for Blue Card (unlike student visa) |
| Passport photos | Biometric |

### For Blue Card Application (in Germany)
- [ ] Anmeldung certificate
- [ ] Employment contract
- [ ] Degree documents
- [ ] Health insurance confirmation
- [ ] Passport + visa
- [ ] Employer declaration

## Timeline to Permanent Settlement

| Milestone | Time | Benefit |
|-----------|------|---------|
| EU Blue Card issued | On arrival | Work + live in Germany |
| PR (Blue Card holder) | After 33 months (or 21 with B1 German) | Permanent residency |
| Citizenship | After 5-8 years (varies by state) | Full rights, EU passport |
