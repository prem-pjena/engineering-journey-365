## Workflow (Used for Every German Session)

```
1. User says "give me German prompt"
2. Agent generates ChatGPT prompt from agent/germany/prompts/
3. User pastes prompt into ChatGPT, completes the session
4. ChatGPT returns a report
5. User pastes report here
6. Agent:
   - Saves report to agent/germany/progress/
   - Updates language_plan.md level progress
   - Adjusts next prompt based on performance
   - Updates timeline if needed
```

## Prompts Structure

Each German prompt sent to ChatGPT covers:
1. **Grammar** — 1 concept per session (cases, verb conjugation, sentence structure, etc.)
2. **Vocabulary** — 10-15 new words on a theme
3. **Speaking/Writing** — 3-5 sentences to construct
4. **Reading** — short paragraph with comprehension questions
5. **Culture tip** — one German cultural note per session
