# 💰 OPTIMIZATION PLAYBOOK (From Report)

These are the techniques that make CTOs want to hire you.

## 1. Semantic Caching
- **What:** Cache LLM responses using vector similarity (not exact match)
- **Impact:** 30% cost reduction for FAQ bots. Latency from 1000ms → 10ms
- **Implementation:** SentenceTransformers + Redis/FAISS

## 2. Model Routing (Cascade)
- **What:** Classify query complexity → route to appropriate model
- **Impact:** $10k/mo → $3.2k/mo (68% reduction)
- **Implementation:** LiteLLM + complexity classifier

## 3. Prompt Compression
- **What:** Strip fluff, collapse whitespace, XML→JSON before sending
- **Impact:** 20-40% token reduction, zero quality loss
- **Implementation:** Preprocessing pipeline

## 4. Context Filtering (RAG)
- **What:** Use cross-encoder rerankers to filter low-signal chunks
- **Impact:** Smaller context → cheaper inference + better accuracy
- **Implementation:** Cohere/BGE reranker after initial retrieval
