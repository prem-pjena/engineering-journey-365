## 🔥 Featured Projects

### 🤖 Multi-Agent MCP Orchestrator
LangGraph-based agent system using Model Context Protocol for secure tool integration. Features multi-agent supervision, dual-channel memory, Ragas evaluation, and cost tracking.
- **Stack:** LangGraph, MCP, FastAPI, Docker, AWS
- **Repo:** [github.com/prem-pjena/agent-orchestrator](https://github.com/prem-pjena/agent-orchestrator)

### 📄 Hybrid RAG Knowledge Assistant
RAG pipeline with hybrid search (dense + BM25), cross-encoder reranking, and Ragas-verified citations achieving 0.92 Faithfulness.
- **Stack:** LangChain, pgvector, FastAPI, Docker, AWS
- **Repo:** [github.com/prem-pjena/rag-system](https://github.com/prem-pjena/rag-system)

### 🧠 Procurement Intelligence RAG
Modular RAG system for extracting procurement intelligence from PDF/HTML documents with semantic retrieval and grounded Q&A.
- **Stack:** LangChain, FAISS, Sentence Transformers, FastAPI
- **Repo:** [github.com/prem-pjena/procurement-intelligence-rag](https://github.com/prem-pjena/procurement-intelligence-rag)
