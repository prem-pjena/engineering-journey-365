## Project 1: AI-powered API Backend
**Timeline:** Month 5 (Nov 2026) — Start of job applications

| Aspect | Detail |
|--------|--------|
| **What** | Production-grade REST API backend with AI integration via LLMs |
| **Skills shown** | FastAPI, PostgreSQL, LLM APIs (OpenAI/Gemini), Docker, AWS, JWT auth |
| **Stack** | FastAPI + PostgreSQL + OpenAI API + Docker + AWS (ECS/EC2) |
| **Features** | CRUD endpoints, LLM-powered features, JWT auth, rate limiting, logging |
| **Database** | Proper indexes, migrations (Alembic), normalized schema, query optimization |
| **Deployment** | Dockerized + deployed on AWS |
| **LinkedIn angle** | "Built and deployed an AI-powered API backend on AWS" |

**What it proves to employers:**
- "I can build production-grade APIs" ✅
- "I can integrate AI into real applications" ✅
- "I understand databases, security, and deployment" ✅

**Matches these job requirements:**
