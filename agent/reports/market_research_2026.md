## 🧠 Key Insights

1. **Supply-demand gap is massive** — 42% YoY growth, 53% skill gap, 1:10 ratio. Premium for Agentic AI skills.
2. **Portfolio > Degree** — Startups on Wellfound hire based on GitHub proof, skip DSA rounds.
3. **PPO path is optimal** — ₹30k internship with PPO → seamless ₹60k+ FT conversion.
4. **Remote arbitrage** — Work for Bangalore/global startups from tier-2 city, maximize savings.
5. **Prompt Engineer title is stagnating** — Must pair with LangChain/RAG/engineering to command premium.
6. **"Agentic AI Engineer" is the premium bracket** — Highest fresher median at ₹12 LPA.
