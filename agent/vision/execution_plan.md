## 🚫 Rules to Never Break

1. **Never skip 2 days in a row** — missing one day is okay (make up 2 hours next day). Missing two breaks the habit.
2. **Never build without validation first** — write README + waitlist before writing code.
3. **Never keep a dead idea alive** — if no signups after launch, kill it within 1 week.
4. **Never work on more than 1 micro-tool at a time** — focus is the only way.
5. **Never compare to funded startups** — you have 1 hour/day and zero dollars. Move differently.
6. **Never stop building in public** — even if no one watches. Consistency compounds.
